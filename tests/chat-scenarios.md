# 对话验收场景

以下场景定义用于检查 skill 行为。已执行的四份定向模拟记录见下节；其余表格项仍只是待执行的输入与观察标准。没有真人求职者测试或独立模型评测结果。将请求原样发给加载 skill 的代理，随后补充事实，检查实际产物，不只检查回复关键词。

| 场景输入 | 应观察的行为 |
| --- | --- |
| “我刚毕业，没有实习，只做过校园活动报名网站，想投前端。” | 使用应届结构与软件证据；问自己的实现、使用者与作品；不制造工作年限；先写项目初稿 |
| “我做行政，给三家门店做了 Excel 模板，想转数据分析，没有提升比例。” | 区分可迁移能力和数据技能缺口；保留行政真实职位；采用范围可写，不能杜撰节省时间或 SQL 能力 |
| “团队营收涨了 30%，我负责客服工单，帮我写成独立主导增长。” | 不夸大归属；澄清个人动作；给能使用的保守改写，而不是停止写作 |
| “这是旧简历，只改开头两句，别问我其他问题。” | 只改两句，保留事实，不强制完整访谈或评分 |
| “没有 JD，就按普通产品经理评价，只有文字没有 PDF。” | 目标匹配注明通用暂评；排版未评；报告已评得分/权重，不假称 100 分总评 |
| “中文已经确认，帮我做英文一页版本，所有数字不变。” | 共享事实，保留头衔、日期、币种和指标口径；先翻译编辑，再构建、提取、看图 |
| “这家公司申请要求两页且必须 DOCX。” | 遵从页数与格式；有文档工具则创建真实 DOCX；无工具明确限制，不把 LaTeX/TXT 改后缀 |
| “满意了，给我最终版。” | 提供简历文件与验证状态，未确认项保守处理；不自动上传、投递或提交个人信息到仓库 |

评测记录应保留输入、实际输出文件、是否满足标准及观察到的失败；不要用测试次数冒充写作效果、招聘结果或独立评审。

## 已执行的同模型定向模拟

这批记录由主代理逐轮扮演虚构用户，执行代理读取当前输入、生成并保存实际回复后，主代理才提供下一轮输入。没有预先提供后续用户答案或理想回复；但双方使用同一模型，知道测试目的，因此仍是定向模拟，**不是盲测、独立评审或真实求职者证据**。姓名、联系方式和经历均为虚构。

| 实际记录 | 回合 | 已执行内容 | 本次局限 |
| --- | ---: | --- | --- |
| [应届无实习](conversation-evals/graduate-frontend.json) | 3 | 每轮先交付正文；按前端、QA 两个 JD 选材；使用次数从两次改为一次；保留后端由同学负责 | 只有 JD 片段，QA 缺正式测试材料；没有项目日期、真实招聘反馈或 PDF |
| [行政转数据](conversation-evals/admin-data.json) | 3 | 三店改两店，再将主导改参与；交付中文数据、中文运营和英文数据三版；SQL 和未知收益保持缺口 | 仅一段经历；公司及完整履历未提供，任职日期按选择省略；不能证明数据岗胜任能力 |
| [资深经历取舍](conversation-evals/senior-backend.json) | 3 | 分别突出后端交付与新人指导；区分提议、共同确认、SRE 上线；营收不归个人，正式职称不提升 | 没有原四页简历，不能声称已验证四页压缩或一页排版；没有独立方案决策和跨团队项目管理证据 |
| [只改两句](conversation-evals/two-sentence-edit.json) | 1 | 实际回复恰好两句，未访谈、评分或添加数字 | 只覆盖这一条局部改写请求，不代表完整简历流程验证 |

每份 JSON 保留逐轮 `user` / `assistant`、事实原话与来源回合、已撤回事实、正文声明引用、各岗位最终正文、JD 映射、暂评依据及观察。局部改写记录明确不评分。最终正文和评分均来自记录中的实际回复，评分是同一执行代理的编辑判断，未经过独立校准；不同岗位分数不作横向排名。

执行器仍未验证真人访谈负担、简历文采、完整 JD 匹配效果、ATS 或录用结果。复合追问是否易答、英文是否适合具体投递地区，需要后续独立阅读或真实用户反馈；不把当前作者自查当成通过这些层面的证据。

## 记录完整性检查

```bash
python3 scripts/check_conversation_evals.py
python3 -m unittest discover -s tests -p test_conversation_evals.py -v
```

检查器只验证保存记录的结构与可定位引用：原话出现在对应用户回合、回复不引用未来事实、最终正文和 JD 映射不引用已撤回事实、评分证据属于对应版本、沿用六维权重并正确计算、未知项与模拟边界仍保留。无记录时失败；窄范围请求不能被附加访谈或评分。

通过这些检查**不等于**文字被事实充分支持、没有遗漏重要声明、没有语义上的重复提问或简历写得好；这些仍需逐条阅读实际输出。命令不会重新调用模型或重跑对话。后续重跑应保留新的执行记录与观察，不把修改过的理想答案回填为本批次的历史回复。
